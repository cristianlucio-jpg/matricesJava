# Proyecto: matricesJava  
_Ejercicios prácticos con matrices en Java_

## Descripción
Este proyecto contiene una serie de ejercicios en **Java** que aplican el manejo de **matrices (arreglos bidimensionales)** para resolver problemas básicos de lógica y programación.  
Forma parte de un portafolio académico y profesional orientado a la práctica de **estructuras de datos y algoritmos**.

---

## Objetivos
- Comprender y aplicar operaciones básicas sobre matrices.  
- Implementar operaciones de **suma, resta y multiplicación** de matrices.  
- Desarrollar programas modulares y bien documentados con **código limpio**.  
- Practicar entrada y salida de datos con `Scanner` y `System.out`.  

---

## Contenido del proyecto

| Ejercicio                  | Clase                       | Descripción |
|----------------------------|-----------------------------|-------------|
| **MatrizSuma**           | `matrizSuma.java`         | Realiza la suma de dos matrices. |
| **MatrizResta**          | `matrizResta.java`        | Calcula la resta entre dos matrices. |
| **MatrizMultiplicacion** | `matrizMultiplicacion.java` | Implementa la multiplicación de matrices. |

---

## Contenido temático
- **Notación y representación** → análisis, diseño e implementación de algoritmos, diagramas de flujo y pseudocódigo.  
- **Conceptos fundamentales** → tipos de datos, operadores, constantes, variables, expresiones y funciones primitivas.  
- **Elementos de un programa** → clases, objetos, métodos, asignación, retorno, creación de objetos.  
- **Control de flujo** → estructuras secuenciales, condicionales y repetitivas (for, while, do-while).  
- **Funciones y procedimientos** → concepto, parámetros por valor y referencia, alcance de variables.  
- **Arreglos bidimensionales (matrices)** → operaciones de suma, resta y multiplicación.
